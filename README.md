### Projeto em desenvolvimento

**Gestão de acessos — Comparador e RBAC Mining**

Uma aplicação local que transforma planilhas de usuários e grupos em informações mais fáceis de explorar:

- Comparação de acessos entre usuários e versões de arquivos.
- Cruzamento de associações usuário/grupo com cadastros de cargos.
- Identificação de conjuntos recorrentes e frequência de grupos por cargo.
- Filtros, relatórios e exportação em Excel e CSV.

Construída com **React, TypeScript, TanStack Table, Radix UI e Web Workers**. O processamento acontece no navegador, sem enviar as planilhas a um servidor. Os resultados apoiam a análise humana de compliance.

*O repositório deste projeto é privado.*
